# Logos Folder

Place your logo files here.

## Required Logo:

1. **reset-global-people-logo.png** - Reset Global People Logo
   - Location: `assets/logos/reset-global-people-logo.png`
   - Description: Circular icon made of numerous small, interconnected shapes, resembling a globe or network
   - Format: PNG with transparent background
   - Size: Recommended 200x200px or larger for high quality
   - The logo should work well on both light and dark backgrounds

## Logo Specifications:

- **Format**: PNG with transparent background
- **Resolution**: High resolution (at least 300 DPI)
- **File Size**: Optimize for web (under 200KB recommended)
- **Aspect Ratio**: Square (1:1) preferred

## Usage:

The logo appears in two places:
1. Top center of the page (header)
2. Event poster (smaller version)

If the logo file is missing, the website will display a fallback circular icon with the text "reset GLOBAL PEOPLE".
